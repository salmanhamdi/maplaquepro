- **Statut** : questions uniquement. **Aucune réponse n'est connue.** Toutes les réponses sont **À VALIDER**. Aucune valeur de ce document n'est normative.
- **Règle** : une propriété obligatoire restant À VALIDER rend la référence inactive (§GL « états normatifs »). Aucune valeur ne doit être déduite des capacités supposées d'une machine.

Pour chaque question, l'atelier indique la valeur, sa source (fiche fabricant, essai atelier…) et, si la question ne s'applique pas, « SANS OBJET ».
